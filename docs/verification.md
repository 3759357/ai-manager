# 검증 기록

2026-10-08 공개본의 별도 가상환경에서 확인했습니다. 실행 방법은 [데모](demo.md)를 참고합니다.

| 검증 | 결과 |
| --- | --- |
| Python 패키지 새 환경 설치 | KI·Toss·Core 및 push 선택 의존성 설치 성공 |
| Core 테스트 | 176개 통과 |
| KI 테스트 | 82개 통과 |
| Toss 테스트 | 38개 통과 |
| 계좌 없는 CLI 데모 | brokers·portfolio-risk·engine status·카드 import/list·allocation 성공 |
| iOS 시뮬레이터 빌드 | 코드 서명 없이 성공, 기존 미사용 반환값 경고 있음 |
| 공개 문서 내부 링크 | 32개 누락 없음 |
| 키·환경설정·DB 제외 | Git ignore 확인, 알려진 로컬 인증값·일부 토큰 패턴 일치 없음 |
| 배포 shell 문법 | bash -n 통과 |
| 공개본 생성 도구 | 원본 저장소에서 제외·비밀값 차단·갱신 보존 등 9개 테스트 통과 |

테스트와 CLI 데모는 공개본에 운영 인증정보를 넣지 않고 실행했습니다. 공개 Git 이력은
운영 저장소에서 가져오지 않았습니다. 개인 번들 네임스페이스·SSH 별칭은 예제 값으로 바꿨습니다.

2026-10-04에 기록된 Linux 배포 테스트 10개 통과는 이전 검증입니다.
이번 Mac 환경에서는 Docker daemon이 실행되지 않아 Linux 배포 시험을 다시 실행하지 않았습니다.
브로커 실계좌 연동·투자 수익성·APNs 기기 수신은 이번 검증 범위에 포함하지 않습니다.
알려진 패턴 검사는 모든 종류의 개인정보·인증정보를 식별하는 검사를 뜻하지 않습니다.
