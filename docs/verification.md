# 검증 기록

## 2026-10-15: 개인 값의 로컬 파일 분리

서버 별칭·앱 번들 ID를 코드에서 빼고 `deploy/local.env`·`ios/Config/Local.xcconfig`(Git 제외)로 옮겼습니다.
공개본 생성 도구는 더 이상 문자열을 바꿔치기하지 않고, 로컬 파일의 실제 값(예시 값 제외)이 공개본 어디에든
나오면 생성을 중단합니다.

| 검증 | 결과 |
| --- | --- |
| 공개본 생성 도구 | 12개 테스트 통과 (로컬 값 차단·예시 값 허용·부분 일치 오탐 방지 포함) |
| Python 테스트 | Core·KI·Toss·배포 전체 통과 |
| 배포 도구 | 서버 미지정 시 안내와 함께 중단, `deploy/local.env`·환경변수 지정 확인 |

iOS 프로젝트의 번들 ID 변수화는 Linux에서 빌드할 수 없어 Xcode 빌드로 별도 확인이 필요합니다.

## 2026-10-13: 내장 가상계좌 제거

가상 잔고·모의 체결·pilot, 앱 운용 화면, 매니저 실행 명령과 전용 LLM 매매 계획을 제거했습니다.
기존 DB·보고·지시 이력은 보존하며, worker는 보고 생성·투자논리 점검·판단 적재·알림을 담당합니다.

| 검증 | 결과 |
| --- | --- |
| Python 테스트 | Core 153개, KI 82개, Toss 38개 통과 |
| 기능 제거 회귀 검증 | 기존 가상계좌 비활성, 지시 자동 실행 없음, 모의 체결 알림 제외, 보고·AI 판단 유지 등 7개 포함 |
| iOS | 시뮬레이터용 앱·테스트 빌드 성공, iPhone 17e / iOS 27.0 테스트 10개 통과 |
| 문서·배포 구성 | 내부 링크 43개, 명령 블록 31개, 배포·LLM shell 문법, reports 및 reports+planner Compose 검증 통과 |

테스트는 임시 DB와 가짜 브로커·알림 응답을 사용했습니다. 운영 서버 배포·실계좌 주문·LLM 인증 호출은 실행하지 않았습니다.
시뮬레이터 빌드에는 기존 터미널 뷰의 미사용 반환값 경고가 남아 있습니다.

2026-10-08 공개본의 별도 가상환경에서 확인했습니다. 실행 방법은 [데모](demo.md)를 참고합니다.
아래 결과는 당시 구현 기준이며 `engine`과 내장 모의 운용은 현재 제공하지 않습니다.

테스트와 CLI 데모는 공개본에 운영 인증정보를 넣지 않고 실행했습니다. 공개 Git 이력은
운영 저장소에서 가져오지 않았습니다. 개인 번들 네임스페이스·SSH 별칭은 예제 값으로 바꿨습니다.

2026-10-04에 기록된 Linux 배포 테스트 10개 통과는 이전 검증입니다.
이번 Mac 환경에서는 Docker daemon이 실행되지 않아 Linux 배포 시험을 다시 실행하지 않았습니다.
브로커 실계좌 연동·투자 수익성·APNs 기기 수신은 이번 검증 범위에 포함하지 않습니다.
알려진 패턴 검사는 모든 종류의 개인정보·인증정보를 식별하는 검사를 뜻하지 않습니다.
