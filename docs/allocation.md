# 비중 규칙과 판단 원장

`core/src/core/allocation.py`는 주문을 만들지 않는 순수 계산 모듈입니다.
`equity_cap`은 총 비중 상한, `sleeve_targets`는 승인된 카드·유효한 판단에 따른 종목별 목표를 계산합니다.
구현은 기준 지수 종가와 날짜가 맞는 입출금 보정 NAV 이력을 입력받습니다.
실제 보유 슬리브 변동성·장부별 회계 연결은 추가 과제입니다.

## 규칙 v1

| 요소 | 계산·초안 값 |
| --- | --- |
| 기본 비중 | `min(0.80, 0.14 / 연율화 변동성) × 추세 계수 × 낙폭 계수`, 하한 0.10 |
| 변동성 | 일간 수익률 EWMA 30일, 연율화 252거래일 |
| 추세 | 200일선의 −2% 아래에서 0.5, +2% 위에서 1.0 |
| 재진입 | 시장이 1년 고점 대비 −20% 이하이고 50일선 회복 시 추세 감산 해제 |
| 낙폭 | 252거래일 롤링 고점, −6%에 0.75·−9%에 0.5 |
| 복귀 | 개선 상태 20거래일 유지 후 한 단계 복귀 |
| 계산 주기 | 5거래일마다 상태 갱신 |
| 비상 상태 | 계좌 낙폭 −15%에 신규 매수 금지 플래그 |

순수 함수의 결과와 실제 주문 차단은 별도입니다. 전체 주문 경로에 이 규칙이 적용된 상태를 의미하지 않습니다.
당일 급락만으로 자동 매수 중지하는 −4% 규칙은 공개 기획에 포함하지 않습니다.

## 카드와 판단

- 카드 수정은 새 draft 버전을 만들고 사용자 승인 전에는 이전 승인본을 유지합니다.
- 판단 원장은 추가 전용이며 카드의 승인 버전과 유효기간에 연결됩니다.
- 틸트는 −2~+2, 기본 가중은 변동성 역수·확신도·틸트를 조합합니다.
- 단일 종목 15%, 고변동 종목 10%, 실적 임박 종목 7%의 상한을 계산에 적용합니다.
- `weakened`는 추가 매수를 막고 `broken`은 승인된 무효화 조건이 확인됐을 때 목표를 0으로 둡니다.
- 관찰 카드는 비중 0, 종목 상한을 적용한 잔여 주식 슬리브는 지수 ETF로 배분합니다.

`core/tests/test_judgments_allocation.py`와 `core/tests/fixtures/allocation_golden.json`으로
연구 코드의 동일 입력·출력 일치, 복귀 지연, 카드 한도·판단 만료를 검증합니다.
[데모](demo.md)의 allocation 명령은 목표를 미리 볼 뿐 주문을 만들지 않습니다.

## 연구 재현

연구 스크립트는 별도 공개 시세를 사용하며 데이터 파일은 저장소에 넣지 않습니다.
저장소 루트에서 연구 의존성을 설치한 뒤 실행합니다.

```sh
python -m pip install numpy pandas matplotlib
cd research/allocation
./fetch_data.sh
python data.py
python final.py
python chart.py
python ohlc.py
python run6.py
```

`fetch_data.sh`가 외부 공개 데이터 저장소를 내려받습니다. 시세 이음새·배당·세금·비용 가정이 포함된
연구이므로 데이터 출처와 `policies.py`, `final.py`의 가정을 함께 검토해야 합니다.
과거 백테스트·계산 일치 테스트는 미래 성과나 손실 상한을 보장하지 않습니다.
